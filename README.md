At the end of the 1st semester of the 1st year in university for our Algorithm Design and Programming project, we built a Java command-line program that compresses and decompresses files using the Lempel–Ziv–Welch (LZW) algorithm. During compression, the program builds a dictionary of byte sequences and replaces sequences it recognizes with numeric codes. During decompression, it rebuilds the dictionary from those codes to recover the original file. We also added commands to compare the file sizes and check whether the restored file matches the original byte for byte.
